## 🎯 Visão do Produto
Para oficinas mecânicas que buscam profissionalismo, o **GESTÃO DE OFICINA 2.0** é um software de gestão de Ordens de Serviço (OS) que centraliza o fluxo de trabalho. Diferente de processos manuais ou planilhas, nossa solução permite que o mecânico atualize o status em tempo real e o administrador aprove orçamentos com agilidade, oferecendo controle total das OS para melhorar a gestão e a praticidade administrativa de pequenas e médias oficinas.

## ⚠️ Definição do Problema
A falta de um sistema centralizado gera desorganização, acúmulo de papelada e perda de tempo na comunicação interna, dificultando o controle de produtividade e o histórico de manutenções.

## 🔄 Metodologia Scrum
O projeto é gerenciado via GitHub Projects e Issues, utilizando Sprints para entregas contínuas de funcionalidades, com foco em agilidade e transparência no desenvolvimento.
